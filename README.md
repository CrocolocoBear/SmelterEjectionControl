# Smelter Ejector

## Summary

Makes smelters, windmills, eitr refineries and all those kind of machines eject items with higher velocity downwards.
Allows creation of funnels and similar if desired.

## License

GNU General Public License v3.0

## Details

Just makes items that get created in any smelter eject with more velocity, so they dont get stuck as easily.

### Dependencies

    BepInExPack Valheim

### Installation (manual)

    Download the latest release archive (zip) file.
    Extract the archive into <Steam Location>\steamapps\common\Valheim\BepInEx\plugins
